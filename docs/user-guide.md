# AI Imaging Optics v1.1 — 사용자 안내

이 앱은 로컬 파일·DB를 사용해 광학 설계를 검토하는 데스크톱 작업대다. 화면에서 설정을 편집하고 저장할 수 있지만, 실제 ML 예측·학습·Zemax·자동 설계 반복·LLM 연결은 아직 실행하지 않는다. 실행 환경과 설치 명령은 [README](../README.md)를 따른다.

## 화면 이동과 소스 파일

Workspace, Explorer, Update model, Add Zemax Sim, Auto design, DB tailoring은 각각의 작업 페이지다. 페이지를 바꾸는 것과 코드 파일 탭을 여닫는 것은 별개다. **코드 파일에만 탭과 닫기 버튼**을 사용한다.

Explorer에서 **Open folder…**로 작업 폴더를 선택하면 실제 디렉터리와 파일이 보인다. 파일을 열면 내용을 읽기 전용으로 표시한다. 코드 탭은 이동하거나 닫을 수 있고, Wrap lines로 긴 줄 표시를 조정한다. 앱 안에서 코드를 실행하거나 덮어쓰지 않는다. **Open in VS Code**는 외부 편집기가 설치되어 있을 때 선택 파일을 여는 기능이다.

오른쪽 **LLM dock**은 상단 LLM panel 버튼이나 **Ctrl+Alt+B**로 현재 페이지와 독립적으로 열고 닫는다(macOS는 Command+Option+B도 지원). 입력한 로컬 draft를 보존하는 영역이며 답변·도구 실행·인증·provider 통신은 연결 전이다. 비밀키나 토큰을 입력할 필요가 없다.

## 설계 데이터 연결

모델을 연결할 때는 `.pth` 자체 대신 모델 **report JSON**을 선택한다. 앱은 report 옆의 모델·DB 참조를 확인한 뒤 저장된 케이스를 읽는다. 모델 파일을 PyTorch로 실행하지 않는다. 목표 JSON도 따로 불러오며 앱에서는 읽기 전용이다.

프로젝트의 로컬 예시는 다음 두 파일이다.

- [training-report.json](../examples/local-demo/training-report.json)
- [target.json](../examples/local-demo/target.json)

예시 DB는 합성 데이터이고 모델 파일은 파일 연결용 dummy다. 화면의 참조 케이스는 새 목표의 best나 실제 Zemax 검증 결과를 뜻하지 않는다. `demo.optics.json`은 내부 파일 서비스 fixture이므로 사용자 시작 세션으로 사용하지 않는다. report를 먼저 불러온 뒤 직접 Save한 세션을 사용한다.

분석 조건은 DB/분석 metadata를 우선한다. 필요한 정보가 없을 때만 표시용 기본값 25°C·560 nm를 사용한다. 파장이 여러 개면 원래 목록을 보존한다. A12와 Relative illumination처럼 없는 수치는 공란이며 0으로 보충하지 않는다.

## 파라미터 편집

**Configure parameters**를 열면 전체 렌즈와 System 항목을 넓은 네이티브 창에서 함께 검토할 수 있다. 각 변수의 활성 여부, 단위, Min/Current/Max를 조정하고 렌즈별 재질과 양면에 공통 적용할 면 종류를 선택한다.

검색과 그룹 필터로 필요한 행을 찾는다. Workspace의 Quick parameters에는 선택된 변수의 현재값과 슬라이더를 표시하고, 범위와 전체 변수 선택은 큰 Parameters 창에서 조정한다.

- **Apply:** 전체 초안을 검증한 뒤 현재 설계에 적용하고, 성공 응답을 확인한 뒤 창을 닫는다. 확인 중에는 중복 적용과 취소를 잠시 막는다. 적용이 실패하면 창과 입력값을 유지한다. 창을 연 뒤 다른 설계가 적용되어 기준이 달라졌다면 입력값을 검토한 후 창을 닫고 다시 연다.
- **Cancel:** 초안을 버리고 현재 설계를 유지한다.
- 범위를 바꿔 Current가 범위 밖으로 나가면 해당 변수의 가까운 경계로 조정한다.
- 비활성화한 변수는 현재값을 유지한다. 현재 면 종류에서 쓰지 않는 계수와 미제공 A12는 편집할 수 없다.
- `학습영역 연결 전`은 실제 조건부 학습 지원 영역이 아직 연결되지 않았다는 뜻이다. 회색 영역이나 숫자를 실제 모델 신뢰도로 임의 해석하지 않는다.

## Workspace, 광학 뷰와 후보

3D viewer와 2D section view를 전환해 렌즈 형상을 본다. 2D에서는 Chief/Marginal 표시를 켜고 끌 수 있으며 Stop을 조정할 수 있다. 기본 Stop은 L3 Rear 면을 따라가고, 직접 이동하면 절대 위치를 유지한다. 로컬 광선 표시는 현재 형상과 굴절률 조건의 기하학 계산이며 Zemax 성능 검증이나 ML 예측 결과가 아니다.

DB 후보 비교는 같은 조건과 출처를 가진 저장된 사례를 사용한다. 선택 케이스의 목표·원값을 확인한 뒤 적용할 수 있고, 후보 적용 직전 상태로 되돌릴 수 있다. 미달 사례를 탐색하는 것과 target을 만족하는 합격 후보는 구분한다. 후보가 없으면 best를 만들어 표시하지 않는다. [후보 판정과 Pareto](development/pareto.md)

### MTF와 Spot 독립 분석창

각 그래프의 **Pop up**을 누르면 별도 창이 열린다. MTF와 Spot을 동시에 열어 나란히 검토할 수 있으며, 분석창이 열려 있어도 Workspace에서 다른 설정을 조작할 수 있다. 같은 Pop up을 다시 누르면 이미 열린 해당 창을 보여준다.

분석창에서 확대·축소, 드래그 이동, 마우스 위치의 값을 확인한다. 창 제목과 출처를 보고 어떤 참조 사례의 저장 결과인지 확인한다. 파라미터를 편집해도 새 ML 예측이나 Zemax 결과가 생성되는 것은 아니다. 분석창의 **X** 또는 **Esc**는 그 창만 닫으며 Workspace는 유지한다.

## Sensitivity matrix

Workspace 하단 분석 영역의 기본 9개 응답은 MTF 네 조건, 1F Spot RMS 직경, H/V full FOV, NA, Distortion이다. 결과가 없으면 `—`가 표시되며 **Calculate · TBU**는 비활성이다.

**Import report…**로 별도 Sobol JSON 결과를 읽으면 출력별·변수별 S1/ST와 CI를 볼 수 있다. 콤보로 S1과 ST를 바꾸고 응답 행을 선택하면 옆 막대가 갱신된다. 이 보고서는 모델 연결에 쓰는 training report와 다른 형식이다. 앱에 자동으로 연결되는 예시 Sobol 숫자는 없다.

- `—`: 미계산·미제공 상태다. 낮은 민감도 또는 0을 뜻하지 않는다.
- `CI: unavailable`: 해당 추정치의 신뢰구간이 보고서에 없다.
- 경고 색: 음수·1 초과 등 확인할 추정치다. 앱은 원본을 잘라서 저장하지 않는다.
- `Stale`: 현재 범위·설계·모델·목표 등이 보고서 당시 설정과 다르다. 이전 결과를 현재 설정의 결과로 사용하지 않는다.

S1/ST는 입력 분포에서 출력 변동에 얼마나 관여하는지 나타낸다. 어느 변수를 올리거나 내려야 목표에 가까워지는지는 알려주지 않는다. ST에는 상호작용도 포함되며 행 합계가 1이 아닐 수 있다. CI는 모델 정확도나 실제 광학 성능을 보증하지 않는다.

보고서는 최대 2 MiB까지 읽는다. 세션에 넣는 보고서는 1 MiB까지다. 큰 보고서 때문에 저장이 거절되면 **Clear report**로 화면에서 해제하고 설정만 저장하거나 작은 보고서로 교체한다. Clear report는 원본 파일이나 설계값을 삭제하지 않는다. 잘못된 보고서를 열어도 기존 정상 결과는 유지한다. [상세 형식과 제한](development/sensitivity.md)

## 준비 화면과 저장

Update model, Add Zemax Sim, Auto design의 설정과 요청 미리보기는 backend 연결을 준비하는 기능이다. 실제 학습 완료, 새 모델 생성, Zemax 데이터 생성, 자동 반복 진행을 뜻하지 않는다. **DB tailoring**은 기능 제목과 TBU 상태만 제공하며 PCA/UMAP 계산이나 새 학습 DB를 생성하지 않는다.

**Save**는 현재 UI·설계 설정과 파일 참조를 세션으로 저장한다. **Open**은 저장된 설정을 복원하며 이전 연산을 재개하지 않는다. **Export**는 세션과 연결된 파일을 ZIP으로 묶는다. 읽기 전용 target 원본이나 기존 모델을 덮어쓰지 않는다.

저장하면 다음 작업 배치도 함께 보존한다.

- 메인 창과 MTF/Spot 분석창의 위치·크기·최대화 여부
- MTF/Spot 분석창의 열림 상태와 그래프 확대·이동 값
- LLM 패널의 표시 여부·폭, Explorer 좌우 분할과 열린 코드 탭
- Workspace 분석 영역의 표시·분할, Sensitivity 보고서와 선택 상태

Open으로 세션을 복원하면 저장 당시 열려 있던 분석창도 함께 복원한다. 이전 모니터가 연결되어 있지 않거나 화면 크기가 바뀌었으면 창이 현재 화면 밖에 남지 않도록 위치와 크기를 보정한다. 이전 v1 세션도 그대로 열며, 저장되지 않았던 배치 값 때문에 오류를 내거나 임의의 화면 위치를 만들어 넣지 않는다.

### 미저장 변경이 있을 때 종료

설계, 초안 또는 창·패널 배치를 바꾼 뒤 앱을 닫으면 **Save / Discard / Cancel** 안내가 나타난다.

- **Save:** 저장 위치 선택과 실제 파일 저장이 성공한 뒤 종료한다. 파일 선택을 취소하거나 저장에 실패하면 앱을 열어 두고 편집 상태를 유지한다.
- **Discard:** 미저장 변경을 저장하지 않고 종료한다. 기존에 저장된 세션 파일을 삭제하지 않는다.
- **Cancel:** 종료를 취소하고 현재 작업을 계속한다.

저장 처리 중 추가 변경이 생겼다면 그 변경까지 저장된 것으로 간주해 자동 종료하지 않는다. 필요한 내용을 다시 확인하고 저장한다.

Compute의 **Test**는 선택한 local/server 대상의 GPU 인식 준비 상태만 확인한다. Mac의 CUDA `unsupported`와 서버 정보가 없는 `not_configured`는 현재 범위에서 정상적인 진단 결과다. `ready`도 ML 학습이나 Zemax 실행 성공을 보증하지 않는다.

새 native v1.1의 Windows 11 실기기·DPI·GPU·파일 대화상자 검증은 별도로 남아 있다. 이전 Windows feedback CI 결과나 Mac offscreen widget 검사를 그 검증으로 간주하지 않는다.
